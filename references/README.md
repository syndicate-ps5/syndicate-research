# Quellen

## Zweck

Dieser Ordner ist das Quellenverzeichnis des öffentlichen Repositories. Jede hier geführte Quelle ist einer konkreten, im Repository verwendeten Aussage zugeordnet.

## Aufnahmeregel

Aufgenommen werden nur Quellen zu verifizierten Inhalten, mit Abrufdatum und mit dem Sachumfang, der tatsächlich verwendet wurde. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

Alle folgenden Seiten wurden am 2026-11-24 abgerufen.
