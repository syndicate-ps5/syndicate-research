# Quellen

## Zweck

Dieser Ordner ist das Quellenverzeichnis des öffentlichen Repositories. Jede hier geführte Quelle ist einer konkreten, im Repository verwendeten Aussage zugeordnet.

## Aufnahmeregel

Aufgenommen werden nur Quellen zu verifizierten Inhalten, mit Abrufdatum und mit dem Sachumfang, der tatsächlich verwendet wurde. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

## Aufgenommene Quellen

### Sony Interactive Entertainment: USB ports guide for PS5 consoles

- URL: <https://www.playstation.com/en-us/support/hardware/ps5-usb-ports-guide/>
- Abgerufen: 2026-11-23
- Verwendet in: [`hardware/`](../hardware/README.md)
- Übernommener Sachumfang: Sony nennt die Modellgruppen CFI-1000, CFI-2000 und CFI-7000. CFI-1000 steht als eigene Modellgruppe. CFI-2000 und CFI-7000 werden gemeinsam als „CFI-2000/7000 model group“ geführt. Die Seite nennt als Abbildungsbeispiel eine Konsole der Modellgruppe CFI-2000 und weist auf modellabhängiges Design hin.
- Nicht übernommen: Porttypen, Geschwindigkeiten, Zubehörhinweise und einzelne Verkaufsnummern. Die Wörter Original, Slim und Pro kommen auf der Seite nicht vor.
