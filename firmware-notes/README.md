# Firmware-Notizen

## Zweck

Dieser Ordner ist für verifizierte Notizen zu Firmware vorgesehen: öffentlich belegte Versionen, belegte Unterschiede, Modellbezüge und dokumentierte Einschränkungen. Hardware-Modellgruppen stehen in [`hardware/`](../hardware/README.md) und werden hier nicht wiederholt.

## Aufnahmeregel

Aufgenommen werden nur verifizierte Inhalte mit Quellenangabe. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

Jede Versionsangabe braucht eine Primärquelle, ein Abrufdatum und eine Evidenzstufe. Nicht belegte Unterschiede bleiben Unknown. Eine vorhandene Notiz ist erst Verified, wenn die Prüfung aus [`methodology/README.md`](../methodology/README.md) abgeschlossen ist. Implemented bedeutet nicht automatisch Verified.
