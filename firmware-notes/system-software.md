# Systemsoftware

## Zweck

Diese Notiz hält nur Aussagen fest, die auf der öffentlichen Versionsliste von Sony stehen. Sie ist keine Anleitung zur Installation und enthält keine Update-Dateien.

## Aufnahmeregel

Aufgenommen werden nur verifizierte Inhalte mit Quellenangabe. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

## Quelle

- Titel der Seite: System software update features for PS5 consoles
- URL: <https://www.playstation.com/en-us/support/hardware/ps5/system-software-info/>
- Abgerufen: 2026-11-24
- Evidenzstufe der folgenden Sätze: Publicly Documented
- Die Seite listet weitere ältere Versionen. Deren Merkmalslisten sind hier nicht übernommen.

Die Verteilerseite <https://www.playstation.com/en-us/support/hardware/ps5/system-software/> verweist auf diese Liste. Im abgerufenen HTML dieser Verteilerseite steht keine Versionsnummer der Form `NN.NN-NN.NN.NN`. Welche Datei zu welcher Versionsnummer gehört, ist Unknown.

## Jüngster Listeneintrag

Der erste Eintrag der Liste ist Version `26.07-14.23.00`. Sony schreibt dazu: „We’ve made some security fixes to the system software.“ Der Inhalt der Korrekturen ist auf der Seite nicht beschrieben und hier Unknown.

## Modellbezug, den die Liste selbst nennt

| Version | Aussage auf der Seite |
| --- | --- |
| `26.06-14.00.00` | Die dort beschriebene Funktion Enhance PSSR Image Quality ist „available only on PS5 Pro“. |
| `26.02-13.00.00` | Die dort beschriebene erweiterte PSSR-Funktion ist „available only on PS5 Pro“. |
| `24.06-10.00.00` | „Adaptive charging is supported on the PS5 CFI-2000 model group, using the USB Type-C port.“ |

Weitere Modellabhängigkeiten derselben Liste sind in dieser Notiz nicht ausgewertet. Ihr Status ist Researching.

## Unknown

- Ob Modellgruppen unterschiedliche Systemsoftware-Builds mit derselben Versionsnummer erhalten.
- Prüfsummen und Dateigrößen der Update-Dateien. Die Verteilerseite nennt Dateinamen und freien Speicherplatz; beides ist hier nicht als Firmware-Identität übernommen.
- Unterschiede zwischen den Versionen außer den drei zitierten Modellbezügen.
