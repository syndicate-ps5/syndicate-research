# Architektur

## Zweck

Dieser Ordner ist für verifizierte Architekturbeschreibungen vorgesehen. Der Projektplan nennt dafür diese Themenfelder: Hardwarearchitektur, Prozessor und Speicher, Betriebssystemgrundlagen, Systemkomponenten, Prozessverwaltung, Dateisystemgrundlagen, Treiberarchitektur und Sicherheitsarchitektur.

Die Aufzählung legt fest, welche Notizen hier später liegen können. Sie ist keine Aussage darüber, dass diese Themen bereits untersucht oder belegt sind.

## Aufnahmeregel

Aufgenommen werden nur verifizierte Inhalte mit Quellenangabe. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

Sicherheitsrelevante Details folgen zusätzlich [`SECURITY.md`](../SECURITY.md). Unveröffentlichte Schwachstellen und Beschreibungen von Umgehungen werden nicht aufgenommen.

## Belegte Produktaussagen

Auf der Produktseite <https://www.playstation.com/en-us/ps5/>, abgerufen 2026-11-24, verwendet Sony diese Bezeichnungen. Evidenzstufe: Publicly Documented. Es sind Produktaussagen, keine Messwerte.

- „custom CPU, GPU and SSD“
- „ultra-high-speed SSD“ für installierte PS5-Spiele
- Ray Tracing in unterstützten PS5-Spielen
- Tempest 3D AudioTech über Fernsehlautsprecher oder kompatible Kopfhörer in unterstützten Spielen

Sony veröffentlicht außerdem eine Seite mit dem Titel „Source Code for Open Source Software Used in PlayStation®5“: <http://doc.dl.playstation.net/doc/ps5-oss/index.html>, abgerufen 2026-11-24. Die abgerufene Seite nennt im Titel Open-Source-Software. Sie nennt im geprüften Titeltext kein Betriebssystem. Die Komponentenliste ist hier nicht übernommen.
