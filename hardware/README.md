# Hardware

## Zweck

Dieser Ordner sammelt verifizierte Angaben zu PlayStation-5-Modellgruppen. Hardware und Firmware werden getrennt geführt. Firmware-Notizen gehören nach [`firmware-notes/`](../firmware-notes/README.md).

## Aufnahmeregel

Aufgenommen werden nur verifizierte Inhalte mit Quellenangabe. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

## Bezeichnungen

Abruf der genannten Seiten: 2026-11-24. Einzelnachweise stehen in den Ordnern und in [`references/README.md`](../references/README.md).

| Modellgruppe | Belegte Bezeichnung | Evidenzstufe | Grenze der Aussage |
| --- | --- | --- | --- |
| [CFI-1000](cfi-1000/README.md) | „PS5 console (CFI-1000 model group)“ | Publicly Documented | „Original“ ist Unknown |
| [CFI-2000](cfi-2000/README.md) | „PS5 console (CFI-2000 model group - slim)“ | Publicly Documented | „slim“ ist auch für CFI-2100 belegt |
| [CFI-2100](cfi-2100/README.md) | „CFI-2100 model group – slim“, auf der US-Seite auch „CFI 2100“ | Publicly Documented | Nicht jede Verkaufsnummer ist zugeordnet |
| [CFI-7000](cfi-7000/README.md) | „PS5 Pro console (CFI-7000 model group)“ | Publicly Documented | Ob jede Landesfassung nur diese Gruppe Pro nennt, ist Researching |

Die USB-Ports-Anleitung, erneut abgerufen 2026-11-24, enthält die Überschriften „PS5 consoles (CFI-1000 model group)“ und „PS5 consoles (CFI-2000/7000 model group)“. Als Abbildungsbeispiel nennt sie eine Konsole der Modellgruppe CFI-2000. Die Wörter Original und Slim kommen dort nicht vor. Vorkommen von „Pro“ auf derselben Seite gehören zu Wörtern wie Program und Productions, nicht zu einer Konsolenbezeichnung.

Die Support-Übersicht führt eine gemeinsame Bildgruppe „PS5 console (CFI-2000/2100/7000 model group)“. Das ist eine andere Gruppierung als die USB-Anleitung.

Portbelegung, Geschwindigkeiten und einzelne Verkaufsnummern bleiben außerhalb dieser Übersicht. Die eine auf einer Produktseite gedruckte Model Number steht nur in [`cfi-2100/README.md`](cfi-2100/README.md).
