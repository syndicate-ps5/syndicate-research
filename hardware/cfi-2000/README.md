# Modellgruppe CFI-2000

## Zweck

Dieser Ordner nimmt verifizierte, quellenbelegte Angaben zur Modellgruppe CFI-2000 auf.

## Aufnahmeregel

Aufgenommen werden nur verifizierte Inhalte mit Quellenangabe. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

## Belegter Stand

Sony nennt in der USB-Ports-Anleitung die Modellgruppe CFI-2000. Für die Beschreibung der USB-Ports führt die Seite CFI-2000 und CFI-7000 gemeinsam als „CFI-2000/7000 model group“. Als Abbildungsbeispiel nennt sie eine Konsole der Modellgruppe CFI-2000.

- Evidenzstufe: Publicly Documented
- Quelle: <https://www.playstation.com/en-us/support/hardware/ps5-usb-ports-guide/>
- Abgerufen: 2026-11-23
