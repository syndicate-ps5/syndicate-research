# Modellgruppe CFI-1000

## Zweck

Dieser Ordner nimmt verifizierte, quellenbelegte Angaben zur Modellgruppe CFI-1000 auf.

## Aufnahmeregel

Aufgenommen werden nur verifizierte Inhalte mit Quellenangabe. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

## Belegter Stand

Sony bezeichnet die Gruppe als „PS5 console (CFI-1000 model group)“ beziehungsweise „PS5 consoles (CFI-1000 model group)“. Evidenzstufe: Publicly Documented. Abgerufen 2026-11-24.

- USB-Ports-Anleitung, eigene Überschrift, getrennt von „CFI-2000/7000 model group“: <https://www.playstation.com/en-us/support/hardware/ps5-usb-ports-guide/>
- Einrichtung, eigener Abschnitt ohne den Zusatz slim oder Pro: <https://www.playstation.com/en-us/support/hardware/ps5-get-started-set-up/>
- Support-Übersicht, eigener Abschnitt, getrennt von „CFI-2000/2100/7000 model group“: <https://www.playstation.com/en-us/support/hardware/ps5/>

## Unknown

Die Arbeitsbezeichnung „Original“ steht in keiner dieser Quellen neben CFI-1000. Eine Suche auf playstation.com hat keinen Satz ergeben, der beide verbindet. Die Produktseite fragt „Is the slim PS5 console the same as the original model?“ und nennt in der Antwort keine Modellgruppe. Evidenzstufe der Zuordnung Original: Unknown.
