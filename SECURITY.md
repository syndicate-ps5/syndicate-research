# Sicherheit

## Responsible Disclosure

Dieses Repository ist eine öffentliche Dokumentationsfläche. Es ist kein Meldeweg für Schwachstellen und enthält keine Exploit-Beschreibungen, keine Umgehungen von Schutzmechanismen und keine unveröffentlichten Sicherheitsdetails.

Sicherheitsprobleme an PlayStation-Produkten sind direkt an Sony zu melden:

- PlayStation Bug-Bounty-Programm: <https://hackerone.com/playstation>
- Product Security Disclosures von Sony: <https://www.playstation.com/en-gb/legal/compliance/productsecuritydisclosures/>

Die Seite zu den Product Security Disclosures beschreibt die Meldung von Sicherheitsproblemen und verweist für PlayStation-Produkte auf das HackerOne-Programm, einschließlich der Einreichungsrichtlinien unter <https://hackerone.com/playstation/policy_scopes>. Für übrige Sony-Assets verweist dieselbe Seite auf <https://secure.sony.com/>.

Details zu einer Schwachstelle gehören in den von Sony genannten Meldeweg. Sie gehören nicht in Issues, Pull Requests, Commits oder Dateien dieses Repositories. Das gilt auch für Proof-of-Concept-Code und für Beschreibungen, die einen Angriff nachvollziehbar machen.

## Geheimnisse

In dieses Repository gehören keine privaten Schlüssel, Tokens, Passwörter, Zugangsdaten oder privaten personenbezogenen Daten. Solche Dateien sind über [`.gitignore`](.gitignore) ausgeschlossen und werden auch bei einem versehentlichen lokalen Auftreten nicht übernommen.

## Arbeitsgrenzen

- Keine unautorisierten Änderungen an Konsolen.
- Keine ungeprüften Sicherheitsbehauptungen.
- Keine Veröffentlichung privater Forschungsdaten aus `syndicate-lab`.
- Keine Releases ohne Freigabe des Owners.

Veröffentlichte, quellenbelegte und vom Owner freigegebene Sicherheitsdokumentation kann später unter denselben Regeln wie jede andere Forschungsnotiz aufgenommen werden. Bis dahin liegt hier keine solche Dokumentation.
