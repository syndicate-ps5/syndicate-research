# Dokumentation

## Zweck

Dieser Ordner erklärt den Aufbau des öffentlichen Research-Repositories und die Lesart der übrigen Verzeichnisse. Er enthält die Arbeitsregeln der Dokumentation, keine Forschungsergebnisse.

## Aufnahmeregel

Aufgenommen werden nur verifizierte Inhalte mit Quellenangabe. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

## Lesart der Verzeichnisse

| Verzeichnis | Gegenstand |
| --- | --- |
| [`hardware/`](../hardware/README.md) | Von Sony öffentlich benannte Modellgruppen |
| [`firmware-notes/`](../firmware-notes/README.md) | Verifizierte Firmware-Notizen |
| [`architecture/`](../architecture/README.md) | Verifizierte Architekturnotizen |
| [`development-notes/`](../development-notes/README.md) | Verifizierte Notizen zu dokumentierten Entwicklungswegen |
| [`methodology/`](../methodology/README.md) | Evidenzstufen und Aufnahmekriterien |
| [`references/`](../references/README.md) | Quellenverzeichnis |
| [`glossary/`](../glossary/README.md) | Festgelegte Begriffe |

Sicherheitsgrenzen stehen in [`SECURITY.md`](../SECURITY.md). Beiträge folgen [`CONTRIBUTING.md`](../CONTRIBUTING.md).

Verantwortungsvolle Sicherheitsforschung hat hier keinen eigenen Inhaltsordner. Unveröffentlichte Hinweise werden über die in `SECURITY.md` genannten Meldewege von Sony geführt. Rohdaten bleiben in `syndicate-lab`.
