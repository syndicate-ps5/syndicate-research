# Entwicklungsumgebung

## Zweck

Dieser Ordner ist für verifizierte Notizen zu öffentlich dokumentierten Entwicklungswegen vorgesehen: Werkzeuge, Compiler, Build-Systeme, Debugging und der zugehörige Dokumentationsstand.

## Aufnahmeregel

Aufgenommen werden nur verifizierte Inhalte mit Quellenangabe. Interne oder unverifizierte Daten gehören ausschließlich in das private Repository `syndicate-lab`.

Vor dem Verweis auf ein fremdes Projekt oder vor der Übernahme von Beispielen gilt die Lizenzprüfung aus [`CONTRIBUTING.md`](../CONTRIBUTING.md). Aktualität, tatsächlicher Funktionsumfang und Lizenz werden an der Primärquelle geprüft und mit Abrufdatum festgehalten. Eine Aufnahme hier ist keine Freigabe für ein Release.

## Aktueller Inhalt

Keine Werkzeugbewertungen und keine Entwicklungsnotizen.
